## 背景

**触发方式**：用户点击 AI Ops 按钮，前端调用 `POST /api/aiops`

**agent 入口（aiops_service.py）**：
```python

```

**初始状态（PlanExecuteState）**：
```python
{
    "input": "诊断当前系统是否存在告警，如果存在告警请详细分析告警原因并生成诊断报告",
    "plan": [],
    "past_steps": [],
    "response": ""
}
```

**工作流图（LangGraph）**：
```
[START] → planner → executor → replanner → (should_continue)
                       ↑                          |
                       |     state.response 非空 → END
                       |     state.plan 非空     → executor（循环）
                       |     state.plan 为空     → END
                       └──────────────────────────┘
```

**respond 触发条件检查**：

### should_continue 路由判断

```python
def should_continue(state):
    if state.get("response"):  # "" → False
        return END
    plan = state.get("plan", [])
    if plan:  # 5 步 → True
        return NODE_EXECUTOR  # → 回到 executor
    return END
```

**路由结果**：→ `executor`（继续执行）

## 阶段六：第 3 轮执行（Executor Step 3）

**当前 plan[0]**：`"调用 get_metrics_anomalies() - 获取当前异常指标，分析性能劣化情况"`

### 工具调用（沙盘模拟）

**调用**：`get_metrics_anomalies(threshold_percentile=0.8)`

**精确计算（error_rate_percent）**：
- metrics.json 中所有服务的 error_rate_percent：90 个值（3服务×30分钟）
  - 45 个 = 0.1%（10:00~10:14，每服务15个）
  - 45 个 = 15%（10:15~10:29，每服务15个）
- sorted_values = [0.1×45, 15×45]
- threshold_index = int(90 × 0.8) = **72**
- sorted_values[72] = **15**（第73个值，属于15%区间）
- threshold = 15，异常条件：value > 15 → **无值严格大于15 → 无异常点**

**精确计算（request_latency_ms）**：
- 90 个值：45 个=100，45 个=5000
- threshold_index = 72，sorted_values[72] = **5000**
- threshold = 5000，异常条件：value > 5000 → **无值严格大于5000 → 无异常点**

**工具返回值**：
```json
{"status": "success", "threshold_percentile": 0.8, "anomalies": {}}
```

> ⚠️ **边界情况**：异常值恰好等于阈值，严格大于判断导致返回空结果。

**Executor 整理结果**：
```
工具调用：get_metrics_anomalies(threshold_percentile=0.8)
执行结果：
- 未检测到超过 80th 百分位阈值的异常指标
- error_rate_percent 阈值=15%，request_latency_ms 阈值=5000ms
- 当前异常值恰好等于阈值，未触发严格大于判断（工具边界情况）
```
