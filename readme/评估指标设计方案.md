# LangSmith 根因诊断准确率评估方案

## 一、评估目标

在 LangSmith 平台上对运维 Agent 的**根因诊断准确率**进行自动化评估，验证诊断系统在故障根因识别上的准确性。

---

## 二、核心评估指标（一总三分）

### 2.1 总指标：根因准确率

```
根因准确率 = 根因服务定位×0.40 + 根因类型识别×0.35 + 证据链完整性×0.25
```

### 2.2 分指标详解

| 分指标 | 权重 | 定义 | 计算方式 |
|-------|------|------|---------|
| **根因服务定位** | 40% | 诊断系统是否正确识别了故障源头服务 | 正确识别数 / 总样本数 |
| **根因类型识别** | 35% | 诊断系统是否正确分类了故障类型 | 故障类型分类正确数 / 总样本数 |
| **证据链完整性** | 25% | 诊断报告中的支撑证据是否完整充分 | 现有证据维度数 / 预期维度数 |

### 2.3 权重分配说明

- **根因服务定位 (40%)**：最核心指标，直接决定"去哪里修"
- **根因类型识别 (35%)**：重要指标，决定"怎么修"，依赖于服务定位
- **证据链完整性 (25%)**：基础指标，保证诊断结论的可信度

### 4.2 评估函数实现

#### 根因服务定位准确率

```python
def evaluate_root_cause_service(example, prediction, **kwargs):
    """评估根因服务识别准确率"""
    gt = example.outputs["root_cause_service"]
    pred = prediction.output.get("root_cause_service")
    correct = gt == pred
    return {
        "key": "root_cause_service_accuracy",
        "score": 1.0 if correct else 0.0,
        "comment": f"Expected: {gt}, Got: {pred}"
    }
```

#### 根因类型识别准确率

```python
def evaluate_root_cause_type(example, prediction, **kwargs):
    """评估根因类型识别准确率"""
    gt_type = example.outputs["root_cause_type"]
    pred_type = prediction.output.get("root_cause_type", "")
    
    # 提取故障类型关键词
    fault_keywords = {
        "timeout": ["超时", "timeout"],
        "memory_leak": ["内存泄漏", "memory leak"],
        "cpu_spike": ["CPU", "cpu"],
        "disk_full": ["磁盘", "disk"],
        "connection_pool": ["连接", "connection"],
        "queue_backlog": ["队列", "queue"],
        "process_crash": ["进程", "crash"]
    }
    
    def extract_type(text):
        for fault_type, keywords in fault_keywords.items():
            if any(kw in text for kw in keywords):
                return fault_type
        return "unknown"
    
    gt_extracted = extract_type(gt_type)
    pred_extracted = extract_type(pred_type)
    correct = gt_extracted == pred_extracted
    
    return {
        "key": "root_cause_type_accuracy",
        "score": 1.0 if correct else 0.0,
        "comment": f"Type: {gt_extracted} vs {pred_extracted}"
    }
```

#### 证据链完整性

```python
def evaluate_evidence_completeness(example, prediction, **kwargs):
    """评估证据链完整性"""
    expected_types = {"deployment_event", "alert", "metrics", "logs", "traces"}
    key_evidence = prediction.output.get("key_evidence", [])
    found_types = {ev.get("type") for ev in key_evidence if isinstance(ev, dict)}
    
    coverage = len(found_types & expected_types) / len(expected_types)
    
    return {
        "key": "evidence_completeness",
        "score": coverage,
        "comment": f"Coverage: {len(found_types & expected_types)}/{len(expected_types)}"
    }
```

#### 综合评分

```python
def evaluate_composite_score(example, prediction, **kwargs):
    """计算根因准确率（加权评分）"""
    scores = {
        "service": evaluate_root_cause_service(example, prediction)["score"],
        "type": evaluate_root_cause_type(example, prediction)["score"],
        "evidence": evaluate_evidence_completeness(example, prediction)["score"]
    }
    
    # 按权重计算
    composite = (
        0.40 * scores["service"] +
        0.35 * scores["type"] +
        0.25 * scores["evidence"]
    )
    
    return {
        "key": "root_cause_accuracy",
        "score": composite,
        "comment": f"Service={scores['service']:.2f}, Type={scores['type']:.2f}, Evidence={scores['evidence']:.2f}"
    }
```

## 五、LangSmith 环境配置

### 5.1 环境变量

```bash
export LANGCHAIN_API_KEY="your_api_key_here"
export LANGCHAIN_ENDPOINT="https://api.smith.langchain.com"
export LANGCHAIN_PROJECT="root_cause_diagnosis"
export LANGCHAIN_TRACING_V2=true
```

### 5.2 创建数据集

```python
from langsmith import Client

client = Client()

# 创建数据集
dataset = client.create_dataset(
    dataset_name="root_cause_diagnosis_v1",
    description="8个故障诊断场景评估数据集"
)

# 加载并上传样本
import json
with open("data/evaluation_dataset.json") as f:
    data = json.load(f)

for scenario in data["scenarios"]:
    client.create_example(
        dataset_id=dataset.id,
        inputs={"scenario_id": scenario["scenario_id"]},
        outputs=scenario["ground_truth"]
    )
```

### 5.3 运行评估

```python
from langsmith import Client
from langsmith.evaluation import evaluate

client = Client()
dataset = client.read_dataset(dataset_name="root_cause_diagnosis_v1")

evaluators = [
    evaluate_root_cause_service,
    evaluate_root_cause_type,
    evaluate_evidence_completeness,
    evaluate_composite_score
]

evaluation_result = evaluate(
    data=dataset,
    target=diagnose_root_cause,
    evaluators=evaluators,
    experiment_prefix="root_cause_diagnosis",
    num_repetitions=1
)
```

## 六、结果分析

### 6.1 查看评估结果

1. 登录 LangSmith 控制面板
2. 进入 Projects → `root_cause_diagnosis`
3. 查看 Experiments 标签中的最新运行
4. 关键查看点：
   - **Summary**：综合评分、各维度平均得分
   - **Metrics 表格**：逐样本得分
   - **Comparison**：不同运行对比

### 6.2 按场景分类分析

```python
# 按故障类型分组统计
results_by_category = {}
for run in client.list_runs(project_name="root_cause_diagnosis"):
    category = run.inputs.get("category")
    if category not in results_by_category:
        results_by_category[category] = []
    results_by_category[category].append(run)

# 计算各类型的准确率
for category, runs in results_by_category.items():
    scores = [get_composite_score(run) for run in runs]
    avg_score = sum(scores) / len(scores)
    print(f"{category}: {avg_score:.2%}")
```

### 6.3 导出评估报告

```python
import pandas as pd

# 汇总所有评估结果
results = []
for run in client.list_runs(project_name="root_cause_diagnosis"):
    feedbacks = client.read_run_feedbacks(run_id=run.id)
    results.append({
        "scenario_id": run.inputs.get("scenario_id"),
        "feedbacks": {fb.key: fb.score for fb in feedbacks}
    })

df = pd.json_normalize(results)
df.to_csv("evaluation_report.csv", index=False)
df.to_excel("evaluation_report.xlsx", index=False)
```

## 九、常见问题

| 问题 | 原因 | 解决方案 |
|-----|------|---------|
| 评估得分低 | 诊断算法不准确 | 检查特征提取、调用链分析 |
| 证据不完整 | 数据源缺失 | 补充 logs/traces 分析 |
| 类型识别失败 | 故障特征提取弱 | 改进关键词提取逻辑 |
| 服务定位失败 | 依赖关系图不完整 | 增强服务依赖分析 |
