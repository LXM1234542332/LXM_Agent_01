# LangSmith 根因诊断准确率评估方案

## 一、评估目标

验证故障根因诊断系统在以下维度的准确性：
- **根因服务识别准确率**：root_cause_service 与标准答案一致的比例
- **根因类型分类准确率**：root_cause_type 分类正确的比例
- **证据完整度**：key_evidence 覆盖的维度数
- **故障传播路径识别**：连锁故障扩散路径的正确性
- **部署事件关联**：部署与故障的因果关联判断

---

## 二、核心评估指标体系

### 2.1 一级指标（主要指标）

| 指标 | 权重 | 计算方式 | 目标值 |
|-----|------|---------|--------|
| 根因服务准确率 | 40% | 正确识别数 / 总样本数 | ≥ 95% |
| 根因类型准确率 | 30% | 故障类型分类正确数 / 总样本数 | ≥ 90% |
| 证据完整度 | 15% | 现有证据维度数 / 预期维度数 | ≥ 80% |
| 部署关联准确率 | 10% | 部署事件识别正确数 / 总样本数 | ≥ 95% |
| 故障传播识别 | 5% | 连锁故障路径正确数 / 有连锁的样本数 | ≥ 85% |

### 2.2 二级指标（细粒度维度）

#### 根因服务维度
- 单服务故障识别（scenario 4, 5, 7）
- 多服务故障识别（scenario 1, 2, 3）
- 单点故障识别（scenario 6, 8）

#### 根因类型维度
- 部署引发的缺陷（scenario 1-5, 7）
- 基础设施故障（scenario 6, 8）
- 资源耗尽类（CPU、内存、磁盘、连接）
- 功能异常类（超时、泄漏、堆积、崩溃）

#### 证据维度
- deployment_event：部署事件识别
- alert：告警时序关联
- metrics：指标异常检测
- logs：错误日志分析
- traces：调用链追踪
- cascading_alert：连锁告警识别

#### 故障传播维度
- 直接影响：故障源头服务
- 一级扩散：直接依赖的服务
- 二级扩散：间接依赖的服务
- 系统级影响：全系统瘫痪

## 四、评估指标实现

### 4.1 根因服务准确率评估

```python
def evaluate_root_cause_service(example, prediction, **kwargs):
    gt = example.outputs["root_cause_service"]
    pred = prediction.output.get("root_cause_service")
    correct = gt == pred
    return {
        "key": "root_cause_service_accuracy",
        "score": 1.0 if correct else 0.0,
        "comment": f"Expected: {gt}, Got: {pred}"
    }
```

### 4.2 根因类型准确率评估

```python
def evaluate_root_cause_type(example, prediction, **kwargs):
    gt_type = example.outputs["root_cause_type"]
    pred_type = prediction.output.get("root_cause_type", "")
    
    # 提取故障类型关键词
    fault_keywords = {
        "timeout": ["超时", "timeout"],
        "memory_leak": ["内存泄漏", "memory leak"],
        "cpu_spike": ["CPU", "cpu"],
        "disk_full": ["磁盘", "disk"],
        "connection_pool": ["连接", "connection"],
        "queue_backlog": ["队列", "queue"],
        "process_crash": ["进程", "crash"]
    }
    
    def extract_type(text):
        for fault_type, keywords in fault_keywords.items():
            if any(kw in text for kw in keywords):
                return fault_type
        return "unknown"
    
    gt_extracted = extract_type(gt_type)
    pred_extracted = extract_type(pred_type)
    correct = gt_extracted == pred_extracted
    
    return {
        "key": "root_cause_type_accuracy",
        "score": 1.0 if correct else 0.0,
        "comment": f"Type: {gt_extracted} vs {pred_extracted}"
    }
```

### 4.3 证据完整度评估

```python
def evaluate_evidence_completeness(example, prediction, **kwargs):
    expected_types = {"deployment_event", "alert", "metrics", "logs", "traces"}
    key_evidence = prediction.output.get("key_evidence", [])
    found_types = {ev.get("type") for ev in key_evidence if isinstance(ev, dict)}
    
    coverage = len(found_types & expected_types) / len(expected_types)
    
    return {
        "key": "evidence_completeness",
        "score": coverage,
        "comment": f"Coverage: {len(found_types & expected_types)}/{len(expected_types)}"
    }
```

### 4.4 部署关联准确率评估

```python
def evaluate_deployment_recognition(example, prediction, **kwargs):
    gt_has_deployment = example.outputs["has_deployment"]
    summary = prediction.output.get("summary", "")
    pred_has_deployment = "部署" in summary or "deployment" in summary.lower()
    
    correct = gt_has_deployment == pred_has_deployment
    return {
        "key": "deployment_recognition",
        "score": 1.0 if correct else 0.0,
        "comment": f"Expected deployment: {gt_has_deployment}, Predicted: {pred_has_deployment}"
    }
```

### 4.5 故障传播识别评估

```python
def evaluate_cascading_fault_recognition(example, prediction, **kwargs):
    gt_has_cascading = example.outputs.get("has_cascading", False)
    gt_affected = set(example.outputs.get("affected_services", []))
    
    summary = prediction.output.get("summary", "")
    # 检查 summary 中是否提到了连锁故障
    pred_has_cascading = any(kw in summary for kw in ["连锁", "扩散", "影响", "cascading"])
    
    correct = gt_has_cascading == pred_has_cascading
    return {
        "key": "cascading_fault_recognition",
        "score": 1.0 if correct else 0.0,
        "comment": f"Cascading: {gt_has_cascading} vs {pred_has_cascading}"
    }
```

### 4.6 综合评分

```python
def evaluate_composite_score(example, prediction, **kwargs):
    scores = {
        "service": evaluate_root_cause_service(example, prediction)["score"],
        "type": evaluate_root_cause_type(example, prediction)["score"],
        "evidence": evaluate_evidence_completeness(example, prediction)["score"],
        "deployment": evaluate_deployment_recognition(example, prediction)["score"],
        "cascading": evaluate_cascading_fault_recognition(example, prediction)["score"]
    }
    
    composite = (
        0.40 * scores["service"] +
        0.30 * scores["type"] +
        0.15 * scores["evidence"] +
        0.10 * scores["deployment"] +
        0.05 * scores["cascading"]
    )
    
    return {
        "key": "composite_score",
        "score": composite,
        "comment": f"Breakdown: {scores}"
    }
```

## 五、评估执行流程

### 5.1 诊断函数封装

```python
from langsmith import traceable

@traceable(name="root_cause_diagnosis")
def diagnose_root_cause(scenario_id: str, base_data: dict) -> dict:
    """调用诊断系统进行根因分析"""
    # 调用实际的诊断 AI/算法
    result = your_diagnosis_system(base_data)
    return {
        "root_cause_service": result["service"],
        "root_cause_type": result["type"],
        "key_evidence": result["evidence"],
        "summary": result["summary"]
    }
```

### 5.2 运行评估

```python
from langsmith import Client
from langsmith.evaluation import evaluate

client = Client()
dataset = client.read_dataset(dataset_name="root_cause_diagnosis_v1")

evaluators = [
    evaluate_root_cause_service,
    evaluate_root_cause_type,
    evaluate_evidence_completeness,
    evaluate_deployment_recognition,
    evaluate_cascading_fault_recognition,
    evaluate_composite_score
]

evaluation_result = evaluate(
    data=dataset,
    target=diagnose_root_cause,
    evaluators=evaluators,
    experiment_prefix="root_cause_diagnosis",
    num_repetitions=1
)
```
