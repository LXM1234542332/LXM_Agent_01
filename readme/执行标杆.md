# Plan-Execute-Replan 诊断流程标杆

## 📚 可用的全部工具

### **本地工具（2个）**

| 工具名称 | 功能 | 参数 | 返回数据 |
|---------|------|------|---------|
| `get_current_time()` | 获取当前时间 | 无 | 当前时间戳 |
| `retrieve_knowledge(query)` | 从知识库检索相关文档 | query: 查询字符串 | 相关文档内容 |

### **MCP 诊断工具（11个）**

| 工具名称 | 功能 | 参数 | 数据来源 | 返回数据 |
|---------|------|------|---------|---------|
| `get_alerts()` | 获取所有告警 | 无 | events.json | 所有 severity >= warning 的告警 |
| `get_error_logs(limit)` | 获取错误日志 | limit: 数量（默认20） | logs.json | ERROR 级别的日志 |
| `get_logs_by_service(service, level, limit)` | 按服务获取日志 | service, level, limit | logs.json | 特定服务的日志 |
| `get_logs_by_time_range(start_time, end_time, limit)` | 按时间范围获取日志 | start_time, end_time, limit | logs.json | 时间范围内的日志 |
| `get_logs_by_keyword(keyword, limit)` | 按关键词获取日志 | keyword, limit | logs.json | 包含关键词的日志 |
| `get_metrics_anomalies(threshold_percentile)` | 获取异常指标 | threshold_percentile | metrics.json | 超过阈值的异常指标 |
| `get_metrics_by_name(metric_name, limit)` | 按指标名获取指标 | metric_name, limit | metrics.json | 特定指标的时间序列 |
| `get_metrics_by_time_range(start_time, end_time, metric_name)` | 按时间范围获取指标 | start_time, end_time, metric_name | metrics.json | 时间范围内的指标 |
| `get_events(limit)` | 获取所有事件 | limit | events.json | 所有事件 |
| `get_events_by_type(event_type, limit)` | 按类型获取事件 | event_type, limit | events.json | 特定类型的事件 |
| `get_deployment_events(limit)` | 获取部署事件 | limit | events.json | 所有部署事件 |

## 📝 关键要点

### **PLAN 阶段**
- 输入：用户请求
- 输出：PlanList（7 个步骤的计划列表）
- 特点：一次性生成，不会改变

### **EXECUTE 阶段**
- 输入：PlanList[current_step_index]
- 输出：Result（工具调用结果）
- 特点：根据计划调用具体的工具

### **REPLAN 阶段**
- 输入：Result
- 输出：决策（继续/重新规划/结束）
- 特点：根据结果判断是否继续或重新规划

### **循环条件**
- 继续：current_step_index += 1，回到 EXECUTE
- 重新规划：删除 PlanList[1:]，重新生成新计划
- 结束：生成最终报告

## 💡 实现建议

1. **在 Planner 中实现 PLAN 阶段**
   - 生成 PlanList
   - 返回计划列表

2. **在 Executor 中实现 EXECUTE 阶段**
   - 根据 PlanList[current_step_index] 调用工具
   - 返回工具结果

3. **在 Replanner 中实现 REPLAN 阶段**
   - 根据 Result 判断是否找到根本原因
   - 判断是否继续执行或重新规划
   - 更新 current_step_index 或 PlanList

4. **在 AIOpsService 中实现循环**
   - 初始化 current_step_index = 0
   - 循环调用 EXECUTE → REPLAN
   - 直到 REPLAN 返回"结束"
